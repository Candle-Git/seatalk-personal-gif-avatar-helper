# 5.2.2 · 打开助手，直达「我的表情」 / My stickers opens first

打开 SeaTalk 表情助手即可整理、搜索和分享收藏。首次使用时，在聊天输入框旁打开表情面板，选择爱心收藏页，再点击「打开我的表情」。

- 修复 SeaTalk Web 3.72 中打开助手或页面静置后偶发的空白。
- 油猴安装名称与界面名称现已统一为「SeaTalk 表情助手」。发送表情时，仍会显示目标会话和所选图片供核对。

[在 Greasy Fork 安装或更新](https://greasyfork.org/zh-CN/scripts/588931)

## English

SeaTalk Sticker Helper opens directly to My stickers, where you can organize, search and share favorites. On first use, open the sticker picker beside the chat box, select the Favorites heart, then choose **Open my stickers**.

- Fixed an issue that could leave SeaTalk Web 3.72 blank when the helper opened or the page was idle.
- Tampermonkey now displays the name **SeaTalk Sticker Helper**. Sending still shows the destination chat and selected stickers for confirmation.

[Install or update on Greasy Fork](https://greasyfork.org/en/scripts/588931)
